# Radiant AI - NPCs Alive - Cyrodiil

**Version**: 3.7
**Nexus Mods**: https://www.nexusmods.com/oblivion/mods/49610
**Author**: Mixxa77

## Description

Restores Bethesda's original Radiant AI behavior, making NPCs act more realistically and dynamically. NPCs will be more likely to be seen randomly around town, in shops or taverns during the day.

## Installation

1. **Download**: Get "RadiantAI - NPCs Alive - Cyrodiil" version 3.7 from Nexus Mods
2. **Extract**: The download contains `RadiantAI - NPCs Alive - Cyrodiil.esp`
3. **Install**: Copy the `.esp` file to:
   ```
   /home/sin/.local/share/Steam/steamapps/common/Oblivion/Data/
   ```

## Load Order

Add to `Oblivion.ini` in `[General]` section:
```
STestFile1=RadiantAI - NPCs Alive - Cyrodiil.esp
```

**Position**: Load after `Oblivion.esm`, before other NPC/AI mods

## Coverage

- Affects all vanilla cities EXCEPT Imperial City
- No compatibility patches needed for base game

## Requirements

- Oblivion (original, not Remastered)
- No OBSE or DLC required
- Compatible with most NPC modifications
