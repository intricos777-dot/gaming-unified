# Steam Tinker Launch Configurations

Profiles for integrating non-Steam games, custom launch options, and controller mappings.

## Usage

1. Install [Steam Tinker Launch](https://github.com/frostworx/steamtinkerlaunch)
2. Copy desired `.stl.toml` profiles to `~/.config/steamtinkerlaunch/profiles/`
3. Add games to Steam via "Add a Non-Steam Game"

## Profiles

- `khz.stl.toml` - Kingdom Hearts Zero (engine args, resolution scaling)
- `te-bonfire.stl.toml` - TE Bonfire (sim mode, debug overlay)
- `mm.stl.toml` - Majora's Mask (time cycle speed, input remap)
- `soh.stl.toml` - Ship of Harkinian (OoT MQ, controller DB)
- `oblivion.stl.toml` - Oblivion via ModOrganizer
