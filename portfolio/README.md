## Development

## Deployment
```bash
# GitHub Pages
git init && git add . && git commit -m "Initial deploy"
gh repo create gaming-portfolio --public --source=. --push
git push -u origin main
# Enable GitHub Pages: Settings > Pages > Source = main branch / root

# OR Netlify
netlify deploy --prod
```
